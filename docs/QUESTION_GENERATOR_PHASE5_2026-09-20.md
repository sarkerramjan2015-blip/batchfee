# AI Question Generator - Phase 5: Institute-Branded Question Paper PDF

## Teacher flow

After questions have passed the Phase 3 review and server-side finalization, the
success dialog offers **Create PDF**. The teacher can then choose:

- Paper size: A4 or Legal
- Margin: Narrow, Normal or Wide
- Text size: Compact, Standard or Large
- Optional separate answer-key page for teacher use

The page-setup dialog includes a visual preview before a PDF is created. After
generation, the teacher can save it to Downloads or send the generated file to
the Android print service.

## Brand and privacy rules

The generated document uses only the current institute profile:

- Institute name, logo, contact details and a subtle institute-name watermark
- Institute name and generated timestamp in the footer
- Page number on every page

No `BatchFee` name, logo, watermark or footer is rendered in the question
paper. The content comes only from the teacher-reviewed, selected questions;
the question paper does not expose model answers unless the teacher explicitly
enables the separate answer-key page.

## Implementation

- `QuestionPaperPdf.kt` creates paginated Android `PdfDocument` files, protects
  page boundaries, writes to a private cache first, exports to Downloads on
  Android 10+, and supplies a print adapter.
- `QuestionBankFoundationScreen.kt` now owns the page-setup/preview and actions
  after finalization.
- The institute record is loaded from the local Room database; paper generation
  fails closed if the institute name cannot be loaded.

## Verification

- `:app:compileDebugKotlin` is the Android compile verification command.
- No debug APK, production PDF, or external deployment is generated by this
  phase implementation.
